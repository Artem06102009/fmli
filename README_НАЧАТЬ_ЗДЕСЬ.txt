ВАЖНО: все файлы этой сборки лежат РЯДОМ, никаких assets/, covers/, books/, readers/ нет.
1. Распакуйте архив; откройте получившуюся папку.
2. Запускайте index.html в браузере для локального просмотра (PDF/FB2/EPUB доступны через HTML-читалки).
3. Для публикации в GitHub репозиторий положите ВСЕ распакованные файлы В КОРЕНЬ репозитория.
4. Проверьте право размещения полных текстов произведений на публичном сайте прежде, чем делать репозиторий общедоступным.
5. Для GitHub Pages: Settings > Pages > Deploy from a branch > main / (root), сохраните.
